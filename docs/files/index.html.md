# `index.html`

파일 역할: LoL·TFT 게임 선택 메인 화면.

[소스 보기](../../index.html) · [파일 목록](../FILES.md)

## 주요 기능

- 공통 헤더, 영상 2개, 게임별 이동 링크와 로딩창 마크업을 제공합니다.
- loading.js 다음 main.js를 실행해 영상 준비와 페이지 전환을 처리합니다.

## 사용처와 수정 시 확인할 점

메인에는 검색 dialog가 없습니다. 게임 선택 후 각 게임 페이지에서 검색합니다.

창 호출 방법과 필수 요소는 [dialog 사용 가이드](../DIALOG-GUIDE.md)를 참고하세요.

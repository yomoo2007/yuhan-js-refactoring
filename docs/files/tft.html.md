# `tft.html`

파일 역할: TFT 검색·전적·통계 화면의 HTML 진입점.

[소스 보기](../../tft.html) · [파일 목록](../FILES.md)

## 주요 기능

- 검색 폼, 프로필, 랭크 그래프, 사용 통계와 매치 목록의 표시 영역을 정의합니다.
- 로딩·오류 dialog 2개, 전체 시너지 패널과 툴팁 3개를 배치합니다.
- defer 스크립트를 선언한 순서대로 실행합니다.

## 사용처와 수정 시 확인할 점

스크립트 순서는 data/tft/tft-set17-data.js의 정적 메타데이터 → 모델 → 샘플 → 랭크·저장·API → 화면 보조 모듈 → tft.js입니다. ID 변경 시 해당 JavaScript 선택자도 함께 수정합니다.

창 호출 방법과 필수 요소는 [dialog 사용 가이드](../DIALOG-GUIDE.md)를 참고하세요.

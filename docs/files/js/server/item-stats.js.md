# `js/server/item-stats.js`

파일 역할: 서버에서 수집한 세트 17 랭크 아이템 통계 누적.

[소스 보기](../../../../js/server/item-stats.js) · [파일 목록](../../../FILES.md)

## 주요 기능

- ItemStats.load(): 저장한 집계와 처리된 매치 ID를 복원합니다.
- ingest(match): 세트 17·큐 1100 실제 경기의 모든 참가자를 매치당 한 번만 집계합니다.
- save(): 저장을 직렬화하고 임시 파일을 교체합니다. snapshot(): 공개 통계 형태를 반환합니다.

## 사용처와 수정 시 확인할 점

server.js에서 사용합니다. 같은 보드의 동일 챔피언·동일 아이템은 중복 제거합니다. 분모는 아이템이 없는 보드를 포함한 해당 챔피언 보드 수입니다. 서버에서 수집한 표본이며 Riot 전체 이용자 통계가 아닙니다.

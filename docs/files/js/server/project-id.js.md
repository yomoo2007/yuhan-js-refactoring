# `js/server/project-id.js`

파일 역할: 실행기와 서버가 같은 실제 프로젝트 폴더에서 실행되었는지 식별합니다.

[소스 보기](../../../../js/server/project-id.js) · [서버 파일 목록](../../../FILES.md#서버와-로컬-실행)

`projectId(directory)`는 실제 경로를 구하고 Windows에서는 대소문자를 통일한 뒤 SHA-256 식별값을 반환합니다. 서버의 `/api/tft/status`와 실행기가 같은 함수를 사용합니다. 상태 응답에는 경로 원문이나 키가 포함되지 않습니다.

프로젝트 식별값이 없는 이전 서버와 다른 복사본의 서버는 자동 재사용하지 않습니다. 기존 서버를 종료하거나 다른 `TFT_PORT`를 지정해야 합니다.

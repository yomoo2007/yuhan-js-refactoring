# `js/tft/tft.js`

파일 역할: TFT 화면 상태·검색·렌더링·사용자 이벤트 통합.

[소스 보기](../../../../js/tft/tft.js) · [파일 목록](../../../FILES.md)

## 주요 기능

- state: 서버, 모드·등수 필터, 표시 개수, 초상화 종류와 통계 표본 수를 관리합니다.
- loading(): 중복 실행을 막고 로딩 표시·AbortController·버튼 복구·오류 재시도를 묶습니다.
- search(): 프로필 조회 → 정규화 → 랭크 저장 → URL 갱신 → 화면 표시를 수행합니다.
- renderProfile/Summary/Usage/Matches/All(): 화면 영역별 렌더링을 담당합니다.
- collectSeason(), stopSeasonCollection(): 이전 페이지를 백그라운드에서 수집하고 중단합니다.
- 검색·새로고침·샘플·즐겨찾기·필터·더보기·상세 펼치기·뒤로가기를 연결합니다.
- 각 요청의 취소·정리 범위를 분리해 이전 응답과 finally가 새 탐색을 방해하지 않게 합니다.
- 매치 ID와 내용이 같은 DOM을 재사용하고 내용 변경 시에도 펼침 상태와 초점을 복원합니다.

## 사용처와 수정 시 확인할 점

tft.html의 마지막 defer 스크립트입니다. 공유 TFT_DATA 참조를 교체하지 않고 내용을 갱신합니다. tft-profile-updated 이벤트로 랭크·아이템 통계 화면에 변경을 알립니다.

뒤로가기·앞으로가기는 검색과 백그라운드 수집을 모두 취소한 뒤 새 주소를 반영합니다. 초기 조회는 방문 기록을 추가하지 않고 현재 주소만 정규화합니다. 동일 주소의 갱신도 중복 기록을 만들지 않습니다.

창 호출 방법과 필수 요소는 [dialog 사용 가이드](../../../DIALOG-GUIDE.md)를 참고하세요.

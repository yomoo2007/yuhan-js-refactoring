# `assets/js/tft/tft-rank.js`

랭크 점수 계산, 날짜별 기록 저장과 LP 그래프 표시를 담당합니다.

- 티어·단계·LP를 비교 가능한 점수로 변환합니다.
- 한국 시간 기준으로 랭크 기록을 날짜별로 정리합니다.
- `TFT_STORE.recordRank()`는 조회한 랭크를 브라우저에 저장합니다. 같은 날짜는 마지막 조회값으로 교체합니다.
- 저장된 기록으로 랭크 요약과 LP 그래프를 표시합니다. 조회하지 않은 날짜는 만들어내지 않습니다.
- `tft-profile-updated` 이벤트를 받으면 화면을 갱신합니다.
- 서비스 워커 등록을 시도합니다.

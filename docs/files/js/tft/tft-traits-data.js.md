파일 역할: 이전 패치의 일부 특성 설명을 보관한 참고 데이터.

[소스 보기](../../../../js/tft/tft-traits-data.js) · [파일 목록](../../../FILES.md)

## 주요 기능

- TFT_TRAITS에 13.20 패치 일부 특성 설명과 발동 구간을 할당합니다.

## 사용처와 수정 시 확인할 점

현재 HTML에서는 불러오지 않습니다. 현재 TFT_TRAITS는 tft-model.js에서 세트 17 traits로 연결하므로 이 파일을 추가 로드하면 현재 데이터가 덮어써질 수 있습니다.

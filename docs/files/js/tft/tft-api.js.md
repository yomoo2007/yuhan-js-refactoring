# `js/tft/tft-api.js`

파일 역할: TFT 프로필·매치 페이지·시즌 기록 조회.

[소스 보기](../../../../js/tft/tft-api.js) · [파일 목록](../../../FILES.md)

## 주요 기능

- TFT_API.fetch(path, { region, force, signal }): LoL과 같은 개인 서버를 통해 데이터를 조회합니다.
- loadProfile(): 계정 조회 후 소환사·리그·첫 20매치를 함께 가져옵니다.
- loadPage(): 시작 위치와 개수를 검사하고 매치 상세를 4개씩 병렬 조회합니다.
- loadSeason(): 실패 매치를 재조회하고 남은 페이지를 조회해 onPage로 전달합니다. 429는 작업당 최대 2회 재시도합니다.

## 사용처와 수정 시 확인할 점

응답 본문을 읽는 도중 발생한 AbortError도 유지합니다. 요청 취소를 실행 주소 오류로 바꾸지 않습니다.

브라우저는 로컬 프록시만 호출합니다. 계정·소환사 404만 kind="not-found"로 분류합니다. 취소와 429는 상세 조회의 일부 실패로 삼키지 않고 호출자에게 전달합니다.

# `css/tft-loading.css`

파일 역할: 메인·TFT 공통 로딩창과 버섯 애니메이션 스타일.

[소스 보기](../../../css/tft-loading.css) · [파일 목록](../../FILES.md)

## 주요 기능

- loading-dialog와 배경, 티모 Canvas·버섯 비행·착지·상태 점멸을 정의합니다.
- 모바일 크기 및 모션 감소 설정을 처리합니다.

## 사용처와 수정 시 확인할 점

index.html과 tft.html에서 사용합니다. 재생 주기·발사 지연은 loading.js의 CSS 변수와 동기화합니다.

창 호출 방법과 필수 요소는 [dialog 사용 가이드](../../DIALOG-GUIDE.md)를 참고하세요.

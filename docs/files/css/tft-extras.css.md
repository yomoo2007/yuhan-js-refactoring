# `css/tft-extras.css`

파일 역할: TFT 오류창·랭크·시너지·아이템 상세 보완 스타일.

[소스 보기](../../../css/tft-extras.css) · [파일 목록](../../FILES.md)

## 주요 기능

- feedback-dialog, 랭크 문양·그래프 툴팁과 전체 시너지 패널을 꾸밉니다.
- 챔피언 초상화·장착 아이템·사용 통계 툴팁을 보완합니다.
- 오류창의 주요 버튼은 `inline-flex`와 `justify-content: center`로 버튼과 문구를 가운데 정렬합니다.

## 사용처와 수정 시 확인할 점

tft.html에서 tft.css 뒤에 사용합니다. 로딩 애니메이션은 tft-loading.css에서 관리합니다.

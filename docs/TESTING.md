# 회귀 검사 실행 방법

[문서 목차](README.md) · [검사 파일 목록](FILES.md#회귀-검사)

## Node.js 검사

Node.js 20 이상에서 프로젝트 루트 기준으로 실행합니다. 추가 패키지 설치는 필요하지 않습니다.

```powershell
node --test tests/regressions.test.js
```

본문 수신 중 취소, 잘못된 JSON 안내, 캐시 열기·읽기·쓰기·정리 실패, 오프라인 캐시 응답과 네트워크 실패, 프로젝트 식별값 및 실행기의 서버 재사용을 검사합니다. 실제 Riot API와 개인 키, 기존 서버 캐시는 사용하지 않습니다.

## 실제 브라우저 검사

```powershell
node tests/serve-browser-tests.js
```

`http://localhost:5185/`를 열면 실제 TFT HTML과 모듈을 별도 검사 서버에서 실행합니다. 화면에 전체 통과 여부와 각 검사 결과가 표시됩니다. 종료하려면 검사 서버 터미널에서 Ctrl+C를 누릅니다. 포트는 `TEST_PORT` 환경 변수로 변경할 수 있습니다.

검사 서버는 프로필·시즌 응답을 지연시켜 다음 동작을 검증합니다.

1. 검색 주소 직접 접속과 같은 프로필 갱신이 방문 기록을 추가하지 않는지 확인합니다.
2. 뒤로가기 후 이전 응답과 이전 작업의 finally가 새 검색·로딩을 방해하지 않는지 확인합니다.
3. 연속 탐색에서도 마지막 주소의 결과와 입력값만 남는지 확인합니다.
4. 백그라운드 수집 중 매치 DOM·초점·전체 시너지 패널이 유지되는지 확인합니다.
5. 초상화 종류 변경 시 매치 카드가 유지되고 아이템이 표시되지 않는지 확인합니다.

검사 페이지는 별도 포트의 브라우저 저장소를 사용하며 실제 Riot API를 호출하지 않습니다. 개인 서버 설정도 읽지 않습니다. 검사 서버는 개발 중 검증 용도입니다.
